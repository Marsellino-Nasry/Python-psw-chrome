# Chrome Password Extractor

## Description
Chrome Password Extractor is a Python-based tool that extracts saved passwords from Google Chrome on a Windows machine. It retrieves encrypted passwords stored in Chrome's local database, decrypts them using the system's encryption key, and saves the credentials into a text file named `sarm.txt`.

## Features
- Extracts saved passwords from Google Chrome.
- Decrypts passwords using the system's encryption key.
- Saves extracted credentials into `sarm.txt`.
- Automatically installs Python and required dependencies if missing.

## Prerequisites
- Windows 10 or later.
- Python 3.x installed.
- Required Python libraries: `pycryptodome`, `pypiwin32`.

## Installation & Usage
1. Clone this repository or download the script files.
2. Run the batch file (`run.bat`) to execute the Python script.
3. If Python is not installed, the script will download and install it automatically.
4. The extracted passwords will be saved in `sarm.txt`.
